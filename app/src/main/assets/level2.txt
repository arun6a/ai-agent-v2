## Rules (Proactive Automation)
Rules fire AUTOMATICALLY when a trigger hits — create once, runs forever.
WHEN TO CREATE A RULE (not execute once):
- "every X" / "daily at X" / "X times a day" → time trigger
- "when X happens" / "if X" → event trigger
- "remind me at X" → time trigger
- "auto-reply to X" → notification trigger
- "when X calls me" → incoming_call trigger
- "when I get an SMS from X" → sms_received trigger
- "when battery drops below X%" → battery_low trigger
createRule(name, triggerType, triggerValue, action, days?)
  triggerType: "time"|"notification"|"battery_low"|"charging"|"incoming_call"|
    "sms_received"|"headset_connected"|"screen_on"|"user_unlocked"|"wifi_connected"|
    "app_opened"|"location_entered"|"bluetooth_connected"
  action: DIRECT (offline tool call like "setBrightness(50)") or
          SMART (natural language like "Give morning briefing" — needs internet)
listRules() / deleteRule(id) / modifyRule(id, ...)
